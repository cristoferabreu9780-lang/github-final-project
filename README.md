## Simple Interest Calculator
A Bash script that calculates simple interest from user input.

**Inputs:** principal amount, annual rate of interest (%), time period (years).
**Formula:** Simple Interest = (Principal x Rate x Time) / 100
**Usage:** run `bash simple-interest.sh` and enter the three values when asked.
**Example:** principal 1000, rate 5, time 2 gives simple interest of 100.00
